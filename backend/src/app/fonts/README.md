# فونت‌ها

برای استفاده از فونت Vazirmatn، فایل‌های زیر رو از لینک زیر دانلود کن و در این پوشه قرار بده:

https://github.com/rastikerdar/vazirmatn/releases

فایل‌های مورد نیاز:
- Vazirmatn-Regular.woff2
- Vazirmatn-Medium.woff2
- Vazirmatn-Bold.woff2

یا می‌تونی از دستور زیر استفاده کنی:

```bash
# دانلود فونت‌ها
curl -L https://github.com/rastikerdar/vazirmatn/releases/download/v33.003/vazirmatn-v33.003.zip -o vazirmatn.zip
unzip vazirmatn.zip
cp fonts/webfonts/Vazirmatn-*.woff2 src/app/fonts/
```

اگر فایل‌های فونت رو نداری، موقتاً می‌تونی از فونت‌های سیستم استفاده کنی.
